## page: procedures/reset-the-ignition-code
- fact: Smart Switch Ignition is a keyless ignition that lets you program your own 1- to 5-digit start code. Most models reprogram with a simple button sequence; the factory default code is locked on some tractors.
- brand: factory default start code is 3-2-1.
- step 1 (start with default): set the parking brake. Wake the control by pressing START (blinks blue). Key in 3-2-1. Press START; it blinks green for a correct code (no green blinking if the parking brake isn't set). Press START again to start.
- step 2 (change code): press START to wake (blinks blue). Press and hold the 1 and 3 buttons for 3 seconds; START turns solid blue. Key in the desired code (video example 2-2-2). Press START to accept; it blinks green. Press START again to start. Use the new code next time.
- step 3 (if default code is locked and won't change): wake with START (blinks blue); enter 1-2-3-1-2-3-1-2-3-1; then press and hold 1 and 3 together for 3 seconds; START turns solid blue (default code lock disabled). Key in desired code (video example 1-1-1); press START (blinks green); press START again to start the engine.
- tip: parking brake must be set for the green blink.

## page: causes/bad-ignition-switch
- fact: not a fault; this is code programming for Smart Switch keyless ignition (a forgotten or changed code stops the tractor starting).
