# Wrong cutting height

## Summary

The cutting height is set wrong for the grass, or set differently on the two sides of the mower. A deck set too low can't handle the amount of grass in thick, tall grass, which spoils the cut and overworks the motor. On a push mower, if the height settings don't match left and right, one side sits lower, the deck is unlevel and one side cuts taller. The fix is easy: raise the deck, or set every wheel to the same height.

## Before you start

- Is the grass thick or tall, and what height is the deck set to?
- On a push mower, is every wheel height lever on the same setting?

Sources: [S2](../../raw/Articles/poweredoutdoors.com/greenworks-lawn-mower-is-cutting-uneven.md), [S4](../../raw/Articles/poweredoutdoors.com/lawn-mower-is-cutting-uneven.md), [S6](../../raw/Articles/poweredoutdoors.com/push-mower-is-cutting-uneven.md)

## Symptoms it produces

- [Uneven cut](../problems/uneven-cut.md): a poor cut in thick, tall grass with the deck set low; or a taller cut on one side when the left and right height settings differ.

## How to confirm

Check the height setting on both sides of the mower (every wheel on a push mower); they must match. Look for damaged parts that change the height on one side. For a poor cut in thick grass, see whether a higher setting cuts better.

Sources: [S4](../../raw/Articles/poweredoutdoors.com/lawn-mower-is-cutting-uneven.md), [S5](../../raw/Articles/poweredoutdoors.com/lawn-mowers-bad-cut-solved.md), [S6](../../raw/Articles/poweredoutdoors.com/push-mower-is-cutting-uneven.md)

## Fix

- Set the left and right (every wheel) height settings the same, and repair any damaged parts that change the height. If the deck still sits unlevel, [level the deck](../procedures/level-the-deck.md).
- Raise the deck to a higher setting for thick, tall grass so the motor isn't overworked.

No parts are named by the Sources. Repair any damaged part that changes the height on one side.

## Tips & life hacks

- Double- or triple-cut tall, thick grass: make the first cut at the highest setting, then lower the deck a little for each extra pass.
