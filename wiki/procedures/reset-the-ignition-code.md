# Reset the ignition code

Fixes: [Bad ignition switch](../causes/bad-ignition-switch.md) (when the problem is a keyless ignition that won't accept the code).

Some lawn tractors have a keyless "Smart Switch" ignition: you start the engine by keying in a 1- to 5-digit code. Most models reprogram with a simple button sequence. On some tractors the factory default code is locked and needs an extra step.

Sources: [S1](../../raw/Articles/searspartsdirect.com/how-to-change-the-smart-switch-ignition-password-on-a-lawn-tractor-video.md)

## Before you start

- Is the parking brake set? The control won't accept a code (no green blink) without it.
- Do you know the current code? The factory default is 3-2-1.
- Only one Source covers this job; check the owner's manual for your model before relying on it.

Sources: [S1](../../raw/Articles/searspartsdirect.com/how-to-change-the-smart-switch-ignition-password-on-a-lawn-tractor-video.md)

## Safety

- Set the parking brake before starting the engine.

Sources: [S1](../../raw/Articles/searspartsdirect.com/how-to-change-the-smart-switch-ignition-password-on-a-lawn-tractor-video.md)

## Tools & parts

- No tools: everything is done on the ignition keypad.

Sources: [S1](../../raw/Articles/searspartsdirect.com/how-to-change-the-smart-switch-ignition-password-on-a-lawn-tractor-video.md)

## Steps

**Start with the default code**

1. Set the parking brake. Press START to wake the control (it blinks blue).
2. Key in 3-2-1 and press START. It blinks green if the code is right.
3. Press START again to start the engine.

**Change the code**

1. Press START to wake the control (blinks blue).
2. Press and hold the 1 and 3 buttons for 3 seconds; START turns solid blue.
3. Key in your new code and press START to accept it (blinks green). Press START again to start. Use the new code next time.

**If the default code is locked and won't change**

1. Press START to wake the control (blinks blue).
2. Enter 1-2-3-1-2-3-1-2-3-1, then press and hold 1 and 3 together for 3 seconds. START turns solid blue: the default-code lock is off.
3. Key in your new code, press START (blinks green), then press START again to start the engine.

Sources: [S1](../../raw/Articles/searspartsdirect.com/how-to-change-the-smart-switch-ignition-password-on-a-lawn-tractor-video.md)

## Brand notes

- The keyless ignition in the manufacturer video is called Smart Switch Ignition; its factory default start code is 3-2-1. Source: [S1](../../raw/Articles/searspartsdirect.com/how-to-change-the-smart-switch-ignition-password-on-a-lawn-tractor-video.md)

## Tips & common mistakes

- No green blink after a correct code usually means the parking brake isn't set. Source: [S1](../../raw/Articles/searspartsdirect.com/how-to-change-the-smart-switch-ignition-password-on-a-lawn-tractor-video.md)

## Verify the fix

Wake the control, key in the new code and press START: it blinks green, and a second press starts the engine.
